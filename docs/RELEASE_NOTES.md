# 0.1.0-preview.4

[下载与安装](DOWNLOAD_PREVIEW.md) · [GitHub Release](https://github.com/Lechoung-J/Pebbleglade/releases/tag/v0.1.0-preview.4)

本版改进图片复制与粘贴的交互。

## 本版调整

- ⌘C 或右键「复制图片」写入系统剪贴板，可粘贴到其他支持图片的应用。
- 复制不在画布增加图片，⌘V 或右键「粘贴图片」才会新增。
- 原 ⌘D 操作明确称为「创建副本」。
- 更新页提供手动下载入口，系统签名校验失败时可前往安装。

## 当前功能

- 在同一画布放置图片、视频、GIF 和 3D 参考。
- 按项目保存画布，整理分组并写下参考判断。
- 连接 Agent 后，通过 MCP 读取和编辑画布。
- 图片和分组备注常驻画布，可原地修改与调整尺寸。
- 空白处右键可添加独立文本框，并关联为单图或整组备注。
- 新画布使用 `.pebb`，兼容读取旧 `.kanvaz`。
- 原生应用名、菜单、图标和安装窗口使用 Pebbleglade 品牌。

## 本版验证

安装包已完成隔离启动、画布写入、MCP 连接及包完整性检查。
DMG 与 ZIP 中的应用文件一致。
