# 0.1.0-preview.5

[下载与安装](DOWNLOAD_PREVIEW.md) · [GitHub Release](https://github.com/Lechoung-J/Pebbleglade/releases/tag/v0.1.0-preview.5)

本版建立固定签名身份，作为应用内更新的过渡版本。

## 本版调整

- 应用使用同一固定自签名证书，为后续版本建立签名基线。
- Preview 3 / 4 用户需手动覆盖安装一次，不必卸载或删除数据。
- 保留系统图片复制、画布备注、独立文本框及 MCP 功能。

## 当前功能

- 在同一画布放置图片、视频、GIF 和 3D 参考。
- 按项目保存画布，整理分组并写下参考判断。
- 连接 Agent 后，通过 MCP 读取和编辑画布。
- 图片和分组备注常驻画布，可原地修改与调整尺寸。
- 空白处右键可添加独立文本框，并关联为单图或整组备注。
- 新画布使用 `.pebb`，兼容读取旧 `.kanvaz`。
- 原生应用名、菜单、图标和安装窗口使用 Pebbleglade 品牌。

## 本版验证

安装包已完成隔离启动、画布写入、MCP 与系统剪贴板检查。
同证书测试版本完成了原生替换和重启，安装前未保存文字与设置均保留。
DMG 与 ZIP 中的应用文件一致。

## 已知范围
