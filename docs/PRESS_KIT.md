# 媒体与品牌资料

Pebbleglade 是一块给设计师和 Agent 共用的情绪板。

## 名称与文案

产品名：Pebbleglade。
请保持一个单词，首字母 P 大写。

主句：让 Agent 看见你的审美。

短介绍：

> 给设计师和 Agent 共用的情绪板。
> 把你的参考、风格和判断，整理成一份 Agent 能读懂的风格摘要。
> 让界面和画面从你的选择开始，而不是从模型平均值开始。

English:

> A moodboard for designers and their agents.
> Turn your references, taste, and design decisions
> into a visual brief. Your agent can read it.
